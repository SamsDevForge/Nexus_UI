# NEXUS AI

A cinematic, single-screen investor landing experience for NEXUS AI, built with
Next.js, React Three Fiber, Drei, Three.js, and Tailwind CSS.

## Local development

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production validation

```bash
npm run build
npm run start
```

## Deploy to Vercel

Import this GitHub repository in Vercel. The framework is detected as Next.js
and no environment variables or backend services are required.

The default Vercel settings are sufficient:

- Build command: `npm run build`
- Output: Next.js default
- Node.js: 20.x or 22.x
